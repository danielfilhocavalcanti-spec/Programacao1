Iniciando estudos DOM

Selecionando os elementos DOM

Posso selecionar os elementos DOM por marca (tagname); por ID; por classe; por seletor (por CSS)

Existe alguns comandos que nós vamos utilizar

Por marca (tagname)

O comando é getElementByTagName

Como está no plural: getElements... eu preciso dizer o numero do elemento que quero utilizar, lembrando que no JS, a contagem dos elementos começa no 0

Por Id

O comando é: getElementById

Preciso atribuir um ID na tag que eu quero manipular

Por ClassName

O comando é o: getElementsByClassName

por seletor (por CSS)
